**Проект:** Погодный информер для веб-приложения
**Команда:** [9/3-РПО-2023/2, Бадмаев Богдан]

---

## **1. Общие сведения**

- **Наименование проекта:**
  Погодный информер

- **Назначение системы:**
  Веб-приложение должно показывать текущую погоду и прогноз для выбранного города.

---

## **2. Требования к функциональности**

Система должна:

- Получать данные о погоде через API.
- Показывать:
  - температуру;
  - описание погоды (солнечно, дождь и т.д.).

- Позволять пользователю вводить название города.
- Обновлять данные по кнопке или при перезагрузке страницы.
- Обновлять тему интерфейса взависимости от погоды
- Отображать данные в удобном виде (текст + иконки).

---

## Архитектура проекта

Проект разделён на клиентскую и серверную части.

### Backend (Node.js + Express)

Обрабатывает запросы и проксирует их к внешним API (ключи не требуются):

- **Nominatim (OpenStreetMap)** — поиск города по названию
- **Open-Meteo** — текущая погода и прогноз
  - основной хост: `https://api.open-meteo.com`
  - резервное зеркало: `https://nodata-api.open-meteo.com` (используется, если основной недоступен)

Эндпоинты:

- `/api/weather?q=город` — текущая погода
- `/api/forecast?lat=&lon=` — почасовой и дневной прогноз
- `/api/geocode?q=город` — координаты города
- `/api/uv?lat=&lon=` — UV-индекс (совместимость)

## **4. Интеграционный план**

- api.js: Вся работа с сетью. Метод fetchWeatherBundle собирает данные о текущей погоде и прогнозе в один объект.

- state.js: Работа с памятью. Сохраняет избранные города в localStorage, чтобы они не пропадали после закрытия вкладки.

- ui.js: Отрисовка интерфейса. Обрабатывает динамические темы (день/ночь) и строит графики.

- script.js: Главный контроллер, управляющий логикой взаимодействия пользователя с модулями.

---

## **5. Инструкция по запуску**

- Установить зависимости: `npm install`
- Опционально создать `.env` (см. `.env.example`):

  ```
  PORT=5500
  ```

- Запустить сервер: `npm start`
- Открыть [http://localhost:5500/](http://localhost:5500/)
