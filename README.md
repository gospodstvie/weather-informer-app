## **1. Общие сведения**

* **Наименование проекта:**
  Погодный информер

* **Назначение системы:**
  Веб-приложение должно показывать текущую погоду и прогноз для выбранного города.

---

## **2. Требования к функциональности**

Система должна:

* Получать данные о погоде через API.
* Показывать:

  * температуру;
  * описание погоды (солнечно, дождь и т.д.).
* Позволять пользователю вводить название города.
* Обновлять данные по кнопке или при перезагрузке страницы.
* Обновлять тему интерфейса взависимости от погоды
* Отображать данные в удобном виде (текст + иконки).

---

##  Архитектура проекта

Проект разделён на клиентскую и серверную части.

### Backend (Node.js + Express)

Обрабатывает запросы и проксирует их к OpenWeather API:

- `/api/weather` — текущая погода
- `/api/forecast` — прогноз
- `/api/uv` — UV-индекс

>  API-ключ хранится на сервере (безопасно)

### Frontend (Vanilla JS)

## **4. Интеграционный план**

* api.js: Вся работа с сетью. Метод fetchWeatherBundle собирает данные о текущей погоде, прогнозе и UV-индексе в один объект.

* state.js: Работа с памятью. Сохраняет избранные города в localStorage, чтобы они не пропадали после закрытия вкладки.

* ui.js: Отрисовка интерфейса. Обрабатывает динамические темы (день/ночь) и строит графики.

* script.js: Главный контроллер, управляющий логикой взаимодействия пользователя с модулями.

PORT=5500

*  перейти по ссылке [http://localhost:5500/]
